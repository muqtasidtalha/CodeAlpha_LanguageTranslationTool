CodeAlpha - AI Language Translation Tool

An interactive desktop translation application built with Python and CustomTkinter, powered by multi-engine translation APIs and Text-to-Speech integration.

Developed as part of the CodeAlpha Artificial Intelligence Internship.

🌟 Key Features

Multi-Language Support: Instant translation across 14+ global languages.

Modern GUI: Sleek dark-mode desktop interface powered by CustomTkinter.

Asynchronous Execution: Non-blocking UI using Python multithreading for smooth performance during API calls.

Text-to-Speech (TTS): Integrated audio playback using gTTS and pygame to listen to translated pronunciations.

Clipboard Integration: One-click button to copy translated text directly to the system clipboard.

🛠️ Tech Stack & Requirements

Python 3.8+

GUI Framework: customtkinter

Translation Engine: translatepy / deep-translator

Text-to-Speech & Audio: gTTS, pygame

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/YOUR_GITHUB_USERNAME/CodeAlpha_LanguageTranslationTool.git
cd CodeAlpha_LanguageTranslationTool


2. Install Dependencies

pip install -r requirements.txt


3. Run the Application

python app.py
